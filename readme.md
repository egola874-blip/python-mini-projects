
# Personal Profile Generator

## About the Project
A beginner-friendly Python project that takes personal information from the user and displays it in a formatted profile.

## Concepts Used
- Variables
- Data Types
- input()
- print()
- Type Conversion
- f-strings

## How to Run
1. Install Python.
2. Open the project folder.
3. Run main.py.

## Example Output
Name: Ekta
Age: 19
City: Delhi
College: JIMS Greater Noida
Course: BTech AIML

Welcome, Ekta!
