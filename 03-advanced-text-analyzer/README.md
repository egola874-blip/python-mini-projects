# Advanced To-Do List Manager

A Python mini-project created to practise and demonstrate important Python List concepts.

## Concepts Covered
- List creation and indexing
- List slicing and updating
- Adding and removing elements
- Searching and sorting
- Nested lists
- List comprehension
- List unpacking
- Shallow copy and deep copy
- List methods and built-in functions
- Enumerate and zip
- List iteration and mutability

## Technologies Used
- Python 3

This project is part of my Python learning journey towards becoming an AI Engineer.
